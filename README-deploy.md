# Deploy: Dawn Brew Coming Soon

## Deploy to Vercel
1. Push code to a GitHub repository
2. Log in to Vercel and click "New Project"
3. Import the repository
4. Click "Deploy" — no build command or output directory needed
5. Once deployed, copy the production URL

## Environment Variables
None required — this is a static site with no backend.

## First-time setup
None required — all content is static and embedded in HTML/CSS. No database or API connections needed.
